# Artificial-Intelligence-Chatbot-
# 🤖 AI Chatbot System

A Java-based console chatbot application that simulates human-like conversations using keyword-based responses and dynamic learning capabilities. The chatbot can interact with users, answer predefined questions, and learn new responses during runtime.

---

# 📌 Project Overview

The  AI Chatbot System is designed to demonstrate the basics of Artificial Intelligence and chatbot development using Java. The chatbot uses simple Natural Language Processing (NLP) concepts through keyword matching and provides automated responses to user queries.

If the chatbot does not recognize a question, it allows the user to teach a new response dynamically, making the system interactive and adaptive during execution.

This project is beginner-friendly and helps learners understand Java programming, Object-Oriented Programming, collections, and AI chatbot fundamentals.
